# Code of Conduct

depth-lens follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

## TL;DR

Be kind. Critique the work, not the person. Assume good faith.

If you see behavior that violates this — harassment, personal attacks, or
sustained disruption — report it by opening a GitHub issue or emailing the
maintainer. Reports stay private.

## What this looks like in practice

- Welcome new contributors. The bar to add a Task or an Adapter is
  intentionally low; help people meet it.
- Empirical findings are welcome even when they contradict prior results.
  "Your benchmark is wrong" must be backed by reproducible numbers, not
  rhetoric.
- Disagreement is fine. Personal attacks, slurs, and sustained off-topic
  arguments are not.

## Scope

Applies to all project spaces: GitHub issues, pull requests, discussions,
and any future chat / forum spaces. Also applies when an individual is
representing the project in public spaces.
