# v1.0 — Anthropic cross-vendor benchmark

> First real-API run of `depth-lens compare` across the Claude 4.x line on a
> graded-difficulty K-hop modular-arithmetic benchmark (`runs/bench.jsonl`).
> Total session spend ≈ $3.84 (576 API calls).

## Setup

- **Models**: claude-haiku-4-5, claude-sonnet-4-6, claude-opus-4-7
- **Task**: graded K-hop modular composition — 4 difficulty *tiers* covering
  both chain length and modulus complexity:

  | Tier | Modulus | Hops | Operator set |
  |---|---|---|---|
  | 1 (easy)      | mod 13  | K=3  | add 1, add 2, add 5 |
  | 2 (moderate)  | mod 23  | K=6  | + add5, mul2, mul3 |
  | 3 (hard)      | mod 47  | K=10 | + sub7, mul5 |
  | 4 (very hard) | mod 97  | K=14 | + sub11, mul11 (6 ops) |

- **Compute knob**: `thinking_budget_tokens` ∈ {1024, 4096, 16384}
- **Samples per cell**: 16 (Wilson 95% CIs in the JSON)
- **Adapter**: `AnthropicAdapter` with `parallel_map(max_concurrent=8)`

## Accuracy

All three Claude 4.x tiers ace the bench at every difficulty and every
budget — frontier reasoning models trivialize structured composition at
this scale.

|                  | tier 1 | tier 2 | tier 3 | tier 4 |
|---|---:|---:|---:|---:|
| Haiku 4.5        | 1.00   | 1.00   | 1.00   | 1.00 |
| Sonnet 4.6       | 1.00   | 1.00   | 1.00   | 1.00 |
| Opus 4.7         | 1.00   | 1.00   | 0.98   | 1.00 |

## Cost — Opus 4.7 detail

This is the more interesting finding. Opus's $/prediction varies by 10× across
the (depth × budget) grid *without changing accuracy*:

|       | budget 1k | budget 4k | budget 16k |
|---|---:|---:|---:|
| tier 1 | $0.0033 | $0.0034 | $0.0044 |
| tier 2 | $0.0069 | $0.0079 | $0.0133 |
| tier 3 | $0.0118 | $0.0151 | $0.0236 |
| tier 4 | $0.0206 | $0.0261 | $0.0347 |

Per-prediction latency (median):

|       | budget 1k | budget 4k | budget 16k |
|---|---:|---:|---:|
| tier 1 | 0.30s | 0.42s | 0.26s |
| tier 2 | 0.63s | 0.44s | 0.41s |
| tier 3 | 0.43s | 0.47s | 0.57s |
| tier 4 | 0.65s | 0.59s | 0.72s |

## Actionable rule we now have evidence for

For workloads that look like graded modular arithmetic up to mod-97 K=14,
on any Claude 4.x model:

> **Use `thinking_budget=1024`.** Pushing to 16384 costs +68% per call at
> the hardest tier and produces zero accuracy gain across all 192 sampled
> instances. Adaptive thinking sizes compute to task difficulty rather
> than filling the budget — so the higher cap is purely a ceiling waste.

This is *exactly* the decision-changing fact depth-lens is built to expose:
sub-second latency improvements are noise; the $/pred number tells you the
story.

## Prior-generation reference: claude-sonnet-4 (May 2025)

To make the cross-vendor generational comparison symmetric with Gemini
(where we tested both 2.5 and 3.1), we re-ran the same bench against
`claude-sonnet-4-20250514` — the first 4-series Sonnet release, May 2025.

|                  | tier 1 | tier 2 | tier 3 | tier 4 |
|---|---:|---:|---:|---:|
| Sonnet 4 (May 2025) | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |
| Sonnet 4.6 (current) | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |

**No generational delta on this task class for Anthropic.** Claude 4 was
already at the ceiling for K-hop modular composition on day one
(2025-05-14). Practitioners using the older Sonnet 4 build for cost
reasons aren't sacrificing accuracy on this kind of workload.

## Limitations

- All cells at 1.00 accuracy → curves are flat → the **shape** of compute
  scaling is invisible here. To see the actual curves with these models we
  need a harder task (genuine K=20+ or non-arithmetic state tracking).
- 16 samples/cell is too few for sub-percent accuracy resolution; Wilson
  CI at acc=1.00/n=16 is `[0.79, 1.00]`. Bigger probes would tighten this.

## Reproducing

```bash
python runs/gen_bench_jsonl.py
export ANTHROPIC_API_KEY=...
depth-lens compare \
    --models anthropic:claude-haiku-4-5,anthropic:claude-sonnet-4-6,anthropic:claude-opus-4-7 \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 \
    --compute 1024,4096,16384 \
    --n-samples 16 \
    --plot bench.png \
    --save-json bench.json
```

Wall time: ~6 min. Spend: ~$3.84.
