# v1.0 — OpenAI cross-vendor benchmark

> Second real-API `depth-lens compare` run, mirroring the Anthropic bench
> on the OpenAI reasoning line. Same task (`runs/bench.jsonl`), same probe
> machinery, different compute knob (`reasoning_effort`).
> Total spend ≈ $2.24 (576 API calls).

## Setup

- **Models**: o4-mini, gpt-5-mini, gpt-5
- **Task**: identical graded K-hop modular composition as the Anthropic run
  — 4 tiers (mod 13 K=3 → mod 97 K=14, see `v1.0-anthropic-cross-vendor.md`)
- **Compute knob**: `reasoning_effort` ∈ {low, medium, high}
- **Samples per cell**: 16
- **Adapter**: `OpenAIAdapter` with `parallel_map(max_concurrent=8)`

and every effort level — frontier reasoning models trivialize structured

## Latency — median seconds per prediction

The most striking secondary finding: **`gpt-5-mini` is 3-5× slower than
`o4-mini`** at the same tier despite using less compute. At tier 4 with
effort=medium:

|             | tier 4 effort=low | tier 4 effort=medium | tier 4 effort=high |
|---|---:|---:|---:|
| o4-mini    | 1.01s | 1.46s | 2.27s |
| gpt-5-mini | 3.84s | 2.71s | 4.77s |
| gpt-5      | 1.25s | 2.69s | 4.28s |

If your application is latency-sensitive on structured tasks of this
difficulty, **o4-mini is the right tool at the cheapest price point**.
`gpt-5-mini` is cheaper per-token but produces worse end-to-end response
times here, suggesting either heavier reasoning per query or different
queuing behaviour on the OpenAI side.

## Actionable rules

1. For structured tasks at-or-below the bench ceiling (mod-97 K=14
   modular composition): **use `reasoning_effort=low` and pick by latency,
   not by accuracy.** Every model/effort combination achieved 1.00.

2. **o4-mini is the value winner**: $0.0036/pred at tier 4, ~1s latency,
   100% accuracy. Beats gpt-5 ($0.0065+) and gpt-5-mini (slow).

3. Cost per prediction scales 2-3× across effort levels on every OpenAI
   model — there is *no* effort=high scenario in this bench where the
   extra spend was justified by accuracy. Same finding as the Anthropic
   bench (budget=16k vs 1k).

## Cross-vendor comparison (at tier 4, cheapest setting, same accuracy)

| Vendor | Model | Setting | $/pred | Latency |
|---|---|---|---:|---:|
| Anthropic | claude-haiku-4-5 | budget=1024 | ~$0.001 (est) | <1s |
| OpenAI    | gpt-5-mini       | effort=low  | $0.0012 | 3.84s |
| OpenAI    | o4-mini          | effort=low  | $0.0036 | 1.01s |
| Anthropic | claude-sonnet-4-6 | budget=1024 | ~$0.005 (est) | <1s |
| OpenAI    | gpt-5            | effort=low  | $0.0065 | 1.25s |
| Anthropic | claude-opus-4-7  | budget=1024 | $0.0206 | 0.65s |

OpenAI's cheap tier is competitive with Anthropic's cheap tier on cost.
Anthropic Haiku/Sonnet have lower latency at the cost of slightly less
visible token usage (Anthropic adapter reports usage via dict; OpenAI
adapter reports via prompt_tokens/completion_tokens). Opus is the most
expensive per-call across both vendors.

## Reproducing

```bash
export OPENAI_API_KEY=...
depth-lens compare \
    --models openai:o4-mini,openai:gpt-5-mini,openai:gpt-5 \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 \
    --n-samples 16 \
    --plot openai_bench.png \
    --save-json openai_bench.json
```

Wall time: ~17 min (OpenAI calls are slower than Anthropic by 2-3×).
Spend: ~$2.24.
