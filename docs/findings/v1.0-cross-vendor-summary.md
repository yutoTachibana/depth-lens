# v1.0 — Cross-vendor benchmark summary

> Real-API runs of `depth-lens compare` on Anthropic, OpenAI, and Google
> Gemini, all on the same K-hop graded-difficulty bench. This is the
> headline v1.0 finding page.
>
> Total spend across all three vendors: ≈ $6 (~¥900).

| Vendor | Models tested | Spend | Findings |
|---|---|---:|---|
| Anthropic | claude-{haiku-4-5, sonnet-4-6, opus-4-7} | $3.84 | All 1.00. Cost varies 10× by (tier × budget). [details](./v1.0-anthropic-cross-vendor.md) |
| OpenAI | {o4-mini, gpt-5-mini, gpt-5} | $2.24 | All 1.00. Latency varies 5× across models at same effort. [details](./v1.0-openai-cross-vendor.md) |
| Google | gemini-2.5-flash (partial, quota-limited) | ~$0 | **One observed cell: tier 1, budget=1024 → acc 0.75** (the only sub-1.00 result of the run). [details](./v1.0-gemini-cross-vendor.md) |

## Headline plot: cheapest-cell $/prediction × tier 4 accuracy

For each vendor, the cheapest setting × highest difficulty:

| Vendor | Model | Setting | tier-4 acc | $/pred (tier 4) | Latency |
|---|---|---|---:|---:|---:|
| Anthropic | haiku-4-5 | budget=1024 | 1.00 | ~$0.001 (est) | <1s |
| OpenAI | gpt-5-mini | effort=low | 1.00 | $0.0012 | 3.84s |
| OpenAI | o4-mini | effort=low | 1.00 | $0.0036 | 1.01s |
| Anthropic | sonnet-4-6 | budget=1024 | 1.00 | ~$0.005 (est) | <1s |
| OpenAI | gpt-5 | effort=low | 1.00 | $0.0065 | 1.25s |
| Anthropic | opus-4-7 | budget=1024 | 1.00 | $0.0206 | 0.65s |
| Google | gemini-2.5-flash | budget=1024 | (quota) | (quota) | (quota) |

**Anthropic Haiku 4.5 is the per-call price floor** when accuracy is at
ceiling. OpenAI o4-mini is the latency-aware second pick. Opus 4.7 is
~20× more expensive than Haiku for identical accuracy on this task class.

## Three structural findings depth-lens surfaced

1. **Adaptive thinking ≠ filling the budget.** Across all Anthropic and
   OpenAI cells, accuracy did not improve when budget/effort was raised.
   Cost did (up to 68% premium at the hardest tier on Opus). Setting
   thinking budgets blind-high is a strict cost loss.

2. **Cheap tiers are not strictly cheap.** OpenAI `gpt-5-mini` is cheaper
   per-token than `o4-mini` but 3× slower per call at tier 4 effort=med.
   For latency-sensitive paths, o4-mini wins despite costing more per
   prediction.

3. **Vendor gap on easy tasks.** Gemini-2.5-flash was the only model
   that did not hit 1.00 on tier 1 (the easiest cell, mod 13 K=3). With
   only 16 samples we can't make strong claims, but the lower bound of
   the 95% CI was 0.51 — far below the other vendors' 1.00. This is a
   one-cell signal worth chasing with a full bench.

## What this bench did *not* surface

mod-97 K=14 is the **ceiling** of the bundled `runs/bench.jsonl`, and
both Anthropic and OpenAI frontier reasoning models trivialise it. To
make the **shape** of compute-scaling visible (the original point of
depth-lens), we need:

- A harder task (~K=20+, or non-arithmetic state tracking, or genuine
  multi-step natural-language reasoning).
- Or much larger n_samples (≥64) so Wilson CIs become tight enough that
  98% vs 100% differences are visible.

Both items are the natural v1.0 → v1.5 follow-up.

## Per-vendor lessons

### Anthropic
- All three Claude 4.x models ace the bench.
- **Adapter required a runtime fix** during the bench: `claude-opus-4-7`
  rejects `thinking.type=enabled` and requires `thinking.type=adaptive +
  output_config.effort`. The adapter now detects this 400 on any worker
  and switches modes idempotently. (commit `3c93303`)
- ~10× cost spread across the (tier × budget) grid at fixed 1.00
  accuracy → the budget knob is purely a cost-controlling lever on
  this task class, not an accuracy lever.

### OpenAI
- All three reasoning models ace the bench.
- `gpt-5-mini` cheaper-per-token but **slow** — production engineers
  picking by $/token will get hurt on user-perceived latency.
- `o4-mini` is the value sweet spot on this task class.

### Google Gemini
- Free tier is unusable for any non-trivial bench (20 req/day for flash,
  0/day for pro).
- One observed cell shows gemini-2.5-flash possibly *not* ceiling on the
  easiest tier — the most interesting result of the whole bench, hidden
  behind a quota wall. Billing must be enabled to investigate further.
- Adapter itself worked correctly under quota errors; the framework's
  retry logic propagated the 429 cleanly.

## Reproducing the full thing

```bash
# Generate task
python runs/gen_bench_jsonl.py

# Anthropic
export ANTHROPIC_API_KEY=...
depth-lens compare \
    --models anthropic:claude-haiku-4-5,anthropic:claude-sonnet-4-6,anthropic:claude-opus-4-7 \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 --compute 1024,4096,16384 \
    --n-samples 16 \
    --plot runs/bench_anthropic.png --save-json runs/bench_anthropic.json

# OpenAI
export OPENAI_API_KEY=...
depth-lens compare \
    --models openai:o4-mini,openai:gpt-5-mini,openai:gpt-5 \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 \
    --n-samples 16 \
    --plot runs/bench_openai.png --save-json runs/bench_openai.json

# Gemini (requires billing enabled)
export GOOGLE_API_KEY=...
depth-lens compare \
    --models gemini:gemini-2.5-flash,gemini:gemini-2.5-pro \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 --compute 1024,4096,16384 \
    --n-samples 16 \
    --plot runs/bench_gemini.png --save-json runs/bench_gemini.json
```

Wall time across all three: ~25 min. Total spend: ~$6 if Gemini has
billing enabled.
