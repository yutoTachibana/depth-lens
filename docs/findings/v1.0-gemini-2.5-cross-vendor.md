# v1.0 — Google Gemini 2.5 cross-vendor benchmark

> Third leg of the v1.0 cross-vendor sweep, now with billing enabled.
> Full 384-call probe across `gemini-2.5-flash` and `gemini-2.5-pro` on
> the same K-hop graded bench used for Anthropic and OpenAI.
> **This is the first run that produced an actual differentiation curve.**

## Setup

- **Models**: gemini-2.5-flash, gemini-2.5-pro
- **Task**: identical graded K-hop bench (`runs/bench.jsonl`, 4 tiers)
- **Compute knob**: `thinking_budget_tokens` ∈ {1024, 4096, 16384}
- **Samples per cell**: 16
- **Wall time**: ~50 min (Pro had heavy adaptive-thinking spikes — single cells hit 17+ min)

## Accuracy

|                  | tier 1 | tier 2 | tier 3 | tier 4 |
|---|---:|---:|---:|---:|
| gemini-2.5-flash | 0.69 / 0.56 / 0.81 | 0.38 / 0.19 / 0.31 | 0.25 / 0.06 / 0.31 | **0.00 / 0.00 / 0.06** |
| gemini-2.5-pro   | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 | 1.00 / 1.00 / 1.00 |

(Each cell = budget 1024 / 4096 / 16384)

`effective_depth(≥0.5)`:
- gemini-2.5-flash: **1** (only the easiest tier)
- gemini-2.5-pro: **4** (every tier)

## The headline finding

**Gemini 2.5 Flash is the only cheap-tier model in the entire v1.0 bench
that doesn't ace this task.** Same-price-class competitors:

| Cheap-tier model | Tier 1 | Tier 2 | Tier 3 | Tier 4 |
|---|---:|---:|---:|---:|
| Anthropic Haiku 4.5 | 1.00 | 1.00 | 1.00 | 1.00 |
| OpenAI gpt-5-mini | 1.00 | 1.00 | 1.00 | 1.00 |
| OpenAI o4-mini | 1.00 | 1.00 | 1.00 | 1.00 |
| **Gemini 2.5 Flash** | **0.69** | **0.38** | **0.25** | **0.00** |

This is exactly the kind of practitioner-actionable fact a single-number
leaderboard cannot show: *for structured composition tasks of the kind in
this bench, Gemini 2.5 Flash is not a viable budget option even though it
prices like one.*

## More compute does not save Flash

Across all four tiers, **raising the thinking budget from 1024 to 16384
did not produce a monotonic accuracy improvement on Flash**:

- tier 1: 0.69 → 0.56 → 0.81 (non-monotonic, peak at high budget)
- tier 2: 0.38 → 0.19 → 0.31 (worst at medium budget)
- tier 3: 0.25 → 0.06 → 0.31 (same)
- tier 4: 0.00 → 0.00 → 0.06 (essentially flat at zero)

Possible interpretation: Flash's thinking is destabilising the answer
rather than refining it — the kind of "overthinking past the solution"
behaviour that depth-lens's `overthinking()` detector exists to flag.

## Pro is fine but slow

Pro hit 1.00 on every cell, matching the other vendors' frontier
reasoners. The cost surprise: **Pro spends a lot of adaptive thinking
even at low budgets**. Median per-prediction wall-clock varied from
~22 s to 600+ s; one cell took 17 minutes. With billing enabled this
isn't a quota issue — it's API queueing / model latency.

## Limitation: this is still Gemini 2.5

Gemini 3.x replaced 2.5 as the headline model in February-May 2026:
`gemini-3.1-pro` and `gemini-3.1-flash-lite`. They use a different
parameter name (`thinking_level` ∈ {low, medium, high}) instead of
`thinking_budget`. The depth-lens Gemini adapter needs updating to
target them; a follow-up bench is at
[`v1.0-gemini-3.x-cross-vendor.md`](./v1.0-gemini-3.x-cross-vendor.md).
