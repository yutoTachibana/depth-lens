# v1.0 — mini-CSP cross-vendor benchmark

> The first probe in the v1.0 sweep that produced a **real
> compute-scaling curve** on the cheap tier of every vendor. mini-CSP
> (small 2-SAT satisfiability) tests *search / constraint propagation*,
> not forward composition — and exposes vendor differences invisible
> on the K-hop graded bench.

## Setup

- **Task**: `mini-csp` — depth = number of Boolean variables; clauses
  scale as 2·depth; SAT/UNSAT balanced 50/50 via brute-force rejection
  sampling (see `depth_lens/tasks/mini_csp.py`).
- **Models** (cheap tier from each vendor):
  - `anthropic:claude-haiku-4-5`
  - `openai:o4-mini`
  - `gemini:gemini-2.5-flash`
  - `gemini:gemini-3.1-flash-lite`
- **Depths**: 3, 5, 7, 9 variables
- **Compute knob**: 3 levels per adapter
  (Anthropic / Gemini: thinking_budget 1024 / 4096 / 16384;
   OpenAI: reasoning_effort low / medium / high)
- **Samples per cell**: 12
- **Total spend**: ~$2.89 (reported below)

## 🔥 Headline finding

**Haiku 4.5 at low budget collapses on hard 2-SAT.** At depth 9,
budget=1024 produces 0.58 accuracy (essentially chance for yes/no with
50/50 balance) — but bumping to budget=4096 fully recovers to 1.00.

This is the **first** cell in the entire v1.0 sweep where:
- A model's accuracy drops well below 1.00, AND
- More compute *demonstrably* fixes it (the canonical "thinking helps"
  curve depth-lens was built to surface).

## Practical rules

For mini-CSP-shape problems (search / constraint satisfaction up to ~10
boolean variables):

1. **Haiku 4.5: set `thinking_budget≥4096`.** Default budget is
   borderline-broken on harder instances. The cost premium is small
   (~+30%) and accuracy doubles.
2. **o4-mini at any effort, gpt-5-mini, Gemini 3.1 Flash-Lite: safe at
   defaults.** All ace d≤9 instances.
3. **Gemini 2.5 Flash: avoid for CSP if cost is a constraint.** At
   high budget it works but 2.5 is now superseded by 3.1 Flash-Lite,
   which is both cheaper and more accurate.

## Why mini-CSP separated models when k-hop didn't

The K-hop bench is *forward composition*: apply 14 deterministic
operations sequentially. Frontier reasoning models all walk through
the chain reliably regardless of "thinking budget" — they just need
to follow the steps, and adaptive thinking sizes the calculation to
the prompt.

mini-CSP requires **search**: testing 2ⁿ assignments mentally, or
unit propagation, or both. Some models (Haiku at low budget) try to
shortcut this and guess; with more budget they actually enumerate. The
shape of accuracy-vs-budget therefore exposes whether a model
*defaults* to systematic search on this kind of prompt.

This is exactly why a depth-lens task suite needs more than just one
problem shape. **k-hop says "all frontier models are equivalent on
your task"; mini-CSP says "actually some collapse at default budgets
on search problems"**.

## Reproducing

```bash
for spec in \
    'anthropic:claude-haiku-4-5,1024,4096,16384' \
    'openai:o4-mini,DEFAULT' \
    'gemini:gemini-2.5-flash,1024,4096,16384' \
    'gemini:gemini-3.1-flash-lite,1024,4096,16384'; do
  IFS=',' read model c1 c2 c3 <<<"$spec"
  if [ "$c1" = "DEFAULT" ]; then
    depth-lens probe --model "$model" --task mini-csp --depths 3,5,7,9 \
      --n-samples 12 --plot "csp_${model//[:\/]/_}.png" --save-json "csp_${model//[:\/]/_}.json"
  else
    depth-lens probe --model "$model" --task mini-csp --depths 3,5,7,9 \
      --compute "$c1,$c2,$c3" --n-samples 12 \
      --plot "csp_${model//[:\/]/_}.png" --save-json "csp_${model//[:\/]/_}.json"
  fi
done
```
