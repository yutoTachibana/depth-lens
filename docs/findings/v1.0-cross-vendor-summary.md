# v1.0 — Cross-vendor benchmark summary

> Real-API runs of `depth-lens compare` on Anthropic, OpenAI, and Google
> Gemini — current generation **and** one generation back where each
> vendor exposes a reasoning-control knob.
> This is the headline v1.0 finding page.
>
> Total spend: ≈ $14.

## Five structural findings depth-lens surfaced

1. **Adaptive thinking ≠ filling the budget.** Across all Anthropic and
   OpenAI cells, accuracy did not improve when budget/effort was raised.
   Cost did (up to 68% premium at the hardest tier on Opus). Setting
   thinking budgets blind-high is a strict cost loss.

2. **Cheap tiers are not strictly cheap.** OpenAI `gpt-5-mini` is cheaper
   per-token than `o4-mini` but 3× slower per call at tier 4 effort=med.
   For latency-sensitive paths, o4-mini wins despite costing more per
   prediction.

3. **Vendor gap on easy tasks.** gemini-2.5-flash was the only frontier
   cheap-tier model that did not hit 1.00 — full bench shows accuracy
   collapsing to 0.00 at tier 4. Same-price-class competitors (Haiku 4.5,
   gpt-5-mini, o4-mini) all aced every cell.

4. **The "generational jump" claim is Gemini-Flash-specific, not
   universal.** When we tested prior-gen models from all three vendors
   on the same bench:
   - Anthropic claude-sonnet-4 (May 2025): 1.00 everywhere — same as current
   - OpenAI o3-mini (Jan 2025): 1.00 everywhere — same as current
   - Gemini 2.5 Flash (Mar 2025): collapses
   - Gemini 2.5 Pro (Mar 2025): 1.00

   So **Anthropic and OpenAI cheap-tier reasoning models were already at
   ceiling for K-hop a year ago**. The dramatic 2.5 → 3.1 Flash jump
   was Gemini Flash catching up to the field, not a universal advance.
   depth-lens specifically detected the Gemini-side anomaly.

5. **Task shape decides whether a budget knob even matters.** k-hop
   (forward composition) is invariant to thinking budget across all
   tested frontier models — every cell at 1.00 regardless of budget.
   mini-CSP (search / constraint propagation) is *not* — Haiku 4.5 at
   budget=1024 collapses to 0.58 on hard 2-SAT instances and recovers
   to 1.00 at budget=4096. **A practitioner deciding "should I pay for
   more thinking?" needs to know *which task class* their workload
   resembles** — and that's exactly the cross-task surface depth-lens
   produces.

## Per-vendor lessons

### Anthropic
- All four Claude reasoning models (3 current + sonnet-4 May 2025) ace
  the K-hop bench. **No generational delta.**
- mini-CSP is where Haiku 4.5 cracks at low budget — useful tuning
  signal for production systems.
- Adapter required a runtime fix during the bench: claude-opus-4-7
  rejects `thinking.type=enabled` and requires
  `thinking.type=adaptive + output_config.effort`. (commit `3c93303`)

### OpenAI
- All four reasoning models (3 current + o3-mini Jan 2025) ace the K-hop
  bench. **No generational delta.**
- gpt-5-mini cheaper-per-token but **slow** — production engineers
  picking by $/token will get hurt on user-perceived latency.
- o4-mini is the value sweet spot on this task class.

### Google Gemini
- **2.5 Flash is the lone weak point** of the entire bench.
- 2.5 Pro was already at ceiling, alongside Anthropic / OpenAI prior gen.
- 3.1 Flash-Lite closes the cheap-tier gap completely.
- The depth-lens-side adapter had to be updated to handle the new
  `thinking_level` parameter for 3.x models.

## What this bench did *not* surface

mod-97 K=14 is the **ceiling** of the bundled `runs/bench.jsonl`, and
every frontier reasoning model since at least January 2025 trivialises
it. To make the **shape** of compute-scaling visible (the original point
of depth-lens), we need:

- Harder task variants — see [`v1.0-mini-csp-cross-vendor.md`](./v1.0-mini-csp-cross-vendor.md)
  for the one that genuinely separated models.
- Or much larger n_samples (≥64) so Wilson CIs tighten enough that
  98% vs 100% differences are visible.

## Reproducing the full thing

```bash
# Generate task
python runs/gen_bench_jsonl.py

# Anthropic — current gen
export ANTHROPIC_API_KEY=...
depth-lens compare \
    --models anthropic:claude-haiku-4-5,anthropic:claude-sonnet-4-6,anthropic:claude-opus-4-7 \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 --compute 1024,4096,16384 \
    --n-samples 16 \
    --plot runs/bench_anthropic.png --save-json runs/bench_anthropic.json

# Anthropic — 2025 prior gen
depth-lens probe \
    --model anthropic:claude-sonnet-4-20250514 \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 --compute 1024,4096,16384 \
    --n-samples 16

# OpenAI — current gen
export OPENAI_API_KEY=...
depth-lens compare \
    --models openai:o4-mini,openai:gpt-5-mini,openai:gpt-5 \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 \
    --n-samples 16

# OpenAI — 2025 prior gen
depth-lens probe --model openai:o3-mini --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 --n-samples 16

# Gemini — current gen (3.1) and prior gen (2.5)
export GOOGLE_API_KEY=...
depth-lens compare \
    --models gemini:gemini-3.1-flash-lite,gemini:gemini-3.1-pro-preview \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 --compute 1024,4096,16384 --n-samples 16

depth-lens compare \
    --models gemini:gemini-2.5-flash,gemini:gemini-2.5-pro \
    --task custom:runs/bench.jsonl:first_int \
    --depths 1,2,3,4 --compute 1024,4096,16384 --n-samples 16

# mini-CSP — the discriminating task
depth-lens probe --model anthropic:claude-haiku-4-5 --task mini-csp \
    --depths 3,5,7,9 --compute 1024,4096,16384 --n-samples 12
```

Wall time end-to-end: ~90 min. Total spend: ~$14 (Gemini billing required).
